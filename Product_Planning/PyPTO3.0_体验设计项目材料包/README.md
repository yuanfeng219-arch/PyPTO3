# PyPTO3.0 体验设计项目材料包

## 项目一句话

PyPTO3.0 是面向 NPU 模型与算子开发者的意图驱动、证据贯通、默认安全的开发与优化工作台，目标是把“能跑”推进到“可信、可解释、可回归、可交付”。

## 早期材料核心叙事（V2 以新稿为准）

1. 现状：开发者最大的问题不是不会用，而是出错后系统没有告诉他发生了什么。
2. 机会：把源码、编译产物、运行证据、硬件知识和版本上下文组织成一条可追踪链路。
3. 方案：以统一工作台承载开发、诊断、验证和准入；以三层信息密度服务不同角色；以 Agent 提供上下文型辅助。
4. 价值：减少盲目试错，缩短从异常发现到责任域定界的时间，并沉淀可复现、可回归的工程资产。

## 使用建议

- 本轮汇报内容准备：优先使用《体验设计汇报叙事与案例 V2》，旧版大纲和逐页稿保留作历史参考，尚未按 V2 全量同步。
- 方案评审：先读《体验设计方案》，再用《材料索引与证据地图》追溯依据。
- 管理层汇报：本轮先使用 V2 文字底稿。现有 PPT 为早期版本，尚未同步新版逻辑与案例。
- 设计/研发协作：结合 `Design/` 下的 Toolkit Studio、Coding Agent、Model Inference Studio、Memory Studio 和编译失败诊断原型。

## 资料边界

本材料包最初基于仓库内截至 2026-08-17 的产品规划、用户体验洞察、用户研究摘要、竞品审核稿和交互原型整理。后续文件以各自版本日期和来源说明为准，V2 叙事与案例稿更新于 2026-09-11。文中“目标”“建议”“假设”均不等同于已上线能力或已验证效果。
