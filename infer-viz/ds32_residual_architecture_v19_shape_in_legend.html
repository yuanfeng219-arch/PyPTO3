DeepSeek V3.2 · Residual Architecture

主干 Hidden State / x 模型在层内与层间持续传递、不断被更新的 token hidden states；shape 通常记作 [B, T, H]，其中 B = Batch Size，T = Sequence Length，H = Hidden Size。上一层的输出 x 会直接成为下一层的输入。
残差分支 / Skip Connection 从当前 x 分叉并绕过 MLA 或 FFN / MoE，在 ⊕ 处与该子层的计算结果重新相加，从而保留原始信息。
+残差相加 / Residual Add 将旁路保留的 x 与子层输出 F(Norm(x)) 做逐元素相加，得到更新后的 hidden state。

标准残差连接

主干 hidden state 通常记成 x。输入 x 一路沿主干向下，经过计算模块后，与从主干分叉出来的 skip connection 在 ⊕ 处相加，得到更新后的 x。

mHC 概念示意

mHC 改变的是 residual stream 在同一个 MLA / MoE 外部的读入与写回方式。也就是说，变化的是连接方式，不是 MLA / MoE 本身的计算逻辑。
