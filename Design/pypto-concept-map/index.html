PyPTO 是什么

PyPTO 是面向昇腾 AI 加速器的 Python 编程框架，核心是 Tile 编程模型。你用 Python 写一个程序，编译器把它从 Tensor 级逐步下沉到 Tile 级，生成两类代码：调度代码跑在 AICPU 上，计算内核跑在 AICore 上。运行时再按任务依赖把它们调度起来。

调度路径 Orchestration 计算路径 InCore 共享环节 性能反馈回路
Tile 编程模型所有计算以片上数据块为单位，贴合硬件的并行能力和内存层级。
多级 IR 与 Pass同一份程序从 Tensor 级逐步下沉到 Tile 级，再生成代码。
MPMD 任务调度AICPU 按依赖把内核任务派发到各个 AICore 核组上执行。

数据怎么流动：Tensor 与 Tile

      
Tensor 在片外全局内存（GM）里，算不动；每个 InCore 任务先把其中一块 load 到片上成为 Tile，在 AIC / AIV 上计算，再 store 回 GM。这是 PTO（Parallel Tensor/Tile Operation）范式的核心。

    

    

      
    

    
Tile 的形状和切法由你决定；编译器负责推断每个 Tile 放在哪块片上内存（InferTileMemorySpace）、分配地址（AllocateMemoryAddr），并把同时用到 Cube 和 Vector 的内核拆成 AIC / AIV 两部分（ExpandMixedKernel）。

  


  

    

      

        

          
分层抽象：谁在哪一层工作

          
同一套框架向不同角色暴露不同层级。

        

        

          
Tensor 级
算法开发者
用 Tensor 级 API 快速实现和验证算法，专注算法逻辑，支持动态形状。

          
Tile 级
性能优化专家
手动决定 Tile 切分、片上内存使用和核间分工，做深度调优。

          
Block / 指令级
系统开发者
在 Tensor / Tile / Block 与 PTO 虚拟指令集层面对接第三方框架或开发工具链。

        

      

      

        

          
五个仓库之间的契约

          
每条边界都有一份明确的接口格式。

        

        

          

            
提供方 → 使用方接口格式

            
              
pypto-lib → pyptoPython API：pypto.language

              
pypto → PTOAS.pto 文件（PTO-ISA MLIR 方言）

              
pto-isa → PTOASC++ 头文件：tile 指令

              
pto-isa → simplerC++ 头文件：ISA 定义

              
pypto → simplerOrchestration C++（PTO2 runtime API）
