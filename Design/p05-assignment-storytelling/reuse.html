输入坐标data-am-columns、data-am-generation 包含 KV Head 列、Batch 行、序列长度和 Batch 的数据量标记。A 保留全矩阵的坐标。B 裁出当前交点附近的 Task，来源标签由同一 Task 记录提供。C 从完整坐标系开始。
Task 生成与身份data-am-tasks 下的 data-pa-task 包含 Task ID、绿色身份标记和 Q Head / Stack 编码。原 morph 在两个状态间移动同一 SVG 节点。A 放大单个原生 Task；B 移动该 Task 的特写；C 保留整张网格，使用原生 morph 把它推进到执行归属。
Block 映射data-am-blocks、data-am-group-labels 与 data-am-block-hit 是真实 Block 边框、批次分组标签和交互热区。A 并置一条 Block 纵剖面，可展开全部 24 个 Block；B 把所选 Block 放在路径末端；C 展开当前 Block 特写，整体仍可点选。
高亮与详情update(selection, true) 负责 is-selected / is-assigned 与 aria-pressed。原 Deck 的 Task 摘要由控制器写入。各裁片共用一个选中状态；外层将 Task 详情放在其附近。选 Block 会高亮同组 Task，选 Task 会定位它的来源与逻辑 Block。

直接复用的样式与展示层变换

直接加载原有 compute-map.css、visualization2-assignment-morph.css、ai-infra-ui.css 和设计令牌。沿用深色 Task、绿色身份图元、蓝色数据容量、行列标注和 Block 容器。Task 身份与 Stack 图元沿用原 Demo 的生成器。

展示层隐藏原组件的页头和操作栏，固定 SVG 标签在源坐标中的尺寸，用 viewBox 裁切与等比放大。A 加展陈底纸与局部选中描边，B 加路径和位移，C 调低非焦点对象透明度、叠加特写与选中描边。新绘制的图形是 B 的叙事连线，表示来源与归属关系。Task、网格、Block、Q Head 和 Stack 都由原组件绘制。

状态与实现边界

每个概念中的裁片挂载独立的原生 SVG 实例，统一使用原 Demo 的 defaultSeqLens、taskInfo()、tasksForBlock() 和组件的 createLayout()。页面只保存演讲关键帧与一份选中状态，原生 update() 将选择应用到所有裁片，C 使用原生 manual() 驱动重排。

原 Demo 的选择事件依附于工作台或 Deck 控制器，直接挂载 SVG 时需要接上演示页的点击与键盘事件。演示页用相同的 Task / Block DOM 命中点和选择结构，保留双向定位。滚轮与拖拽由演示构图接管，避免局部裁片的镜头被意外改变。深层 Inspector 和双击下钻留在原工具中。

路径动画、裁切比例和淡化用于演讲聚焦。实际对象和归属来自原模型，Block 表达逻辑分配。
