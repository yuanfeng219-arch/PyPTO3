## 第 2 轮探索记录

[打开原型](index.html) · [第 1 轮记录](exploration-notes.md)

本轮选用 **共享原点＋轻填充交集＋左右弧线重排＋并列侧视圆盘**。默认自动播放 24 秒。播放条可以直接定位各幕；交集形成后，可点按中心菱形联动三个小节点。

| 在同一 HTML 实现并比较的方向 | 观察与取舍 |
|---|---|
| [A · 细箭头、轻纹理、对角重排](index.html?study=arrow&t=0) | 箭头指向清楚，但容易让人联想到数据流；纹理与交叉区引线竞争。直线收拢时三个副本较早贴近，跟踪其中一组更费力。 |
| [B · 虚线准星、边界强调、弧线重排、错位圆盘](index.html?study=ray&t=0) | 测量感较强，但重复准星和描边分散中心注意力。错位盘能保留轮廓，投影下却更难沿水平方向快速扫读。 |
| [C · 共享原点、轻填充、弧线重排、并列圆盘](index.html?study=origin&t=0) | **最终默认。** 三条结构线说明谁在观察同一个对象，静态交集靠色面辨识；上下两条弧线保留更多侧向空间。每层三盘在同一水平线上，三种视角容易跨层对照。 |

备选仅通过 URL 参数访问，使用同一套图元、时间轴和播放控制。

- **独立观测**：开场静止。三个视角用细线连接同一个 Paged Attention 定位点。直接复用正式 P11 SVG 图标，副标为 What / Where / When。
- **建立交集**：色面、三组短引注和中心算子共同交代关系。移除 A01、卡片和旁白。联动只用中心菱形与三个小节点，不表示真实执行映射。
- **空间重组**：左侧切片上行成为 Device，右侧下行成为 Iteration。原件锚点从开场到终态都在同一坐标，重组后对应 AI Core。弧线让两侧先拉开纵向间距，再回到中轴。
- **侧视层级**：每行保留三枚间隔清楚、独立命名的截面；横向定位线把三视角归为同一执行范围。行宽随粒度收窄，只表示观察范围。聚焦由外括线、亮度和纵轴表达。
- **版式**：恢复正式 P11 页眉和完整标题。左栏只保留三行原副标题，右侧演绎。仓库中的 exploration 作为迭代底稿；附件环境未找到 `index(3).html` 或 img5 图像，正式页眉和图标以本地 Deck 与本轮文字为准。

本机 Chrome 以 1280 × 720 对照三个方向，检查两条重组轨迹、阶段定位、重播、回拖、中心点选与结束停帧。下一步值得在实际投影环境检查弱化层级的对比度，并请观众在无旁白时复述「同一算子、三个视角」与「每层仍有三个视角」。
