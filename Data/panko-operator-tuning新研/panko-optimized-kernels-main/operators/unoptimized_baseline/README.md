# Unoptimized Baseline

This category is for PANKO runs that start from a baseline with no prior optimization. No runs have been added yet.

Add each operator under `<operator>/`, with `nodes/`, `report/`, `optimization.md`, and `searchstate.json` directly inside it. Replace the live nodes and search logs on updates; retain existing reports and append new best kernels and their provenance records.

See the [repository README](../../README.md) for naming, provenance, and update conventions.
